# DronePropA - Drone Propeller Fault Analysis

## Overview
This project explores drone motion trajectories under
healthy and defective propeller conditions.

## Dataset
DronePropA: Motion Trajectories Dataset for Commercial
Drones with Defective Propellers.

The dataset contains 130 MATLAB data files.

## Technologies
- Python
- NumPy
- SciPy
- Pandas
- Matplotlib
